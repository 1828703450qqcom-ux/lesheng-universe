# 90 秒，讲清楚一次音乐相遇

演示前：在本地注册虚构账号，清空无关标签页，准备自己有权使用的照片/音频，不使用现有线上用户数据。页面示例数量不能作为真实用户量讲述。

## 0–15 秒：不是再做一个播放器

首页展示星空、角色和网格星球。旁白：

“音乐能回答听什么。但有时候，我们更想知道，有没有人理解此刻的自己。乐生宇宙让一个故事变成角色，再让一首歌变成一次相遇。”

## 15–40 秒：角色为什么属于你

打开照片、故事与 MBTI 步骤，观察实时预览和生成依据。

“色彩来自照片，性格线索来自我填写的故事和 MBTI，道具来自目标。这里用本地分析和可复现规则生成，不需要付费图像 API，也不把照片当成人格诊断。”

## 40–60 秒：站到一首歌旁边

进入广场，点击中央屏幕播放完整 SoundHelix 示例曲目，点开角色。

“我的角色可以进入同一个音乐空间。无需一直找话题，也能先听见彼此。”

## 60–80 秒：用歌曲开口

进入送歌页，选择虚构角色、代表歌曲和一句留言，展示明信片与关系记忆入口。商业歌曲没有授权音源时不要演示成可以播放原曲。

“与其尴尬地问一句在吗，不如送一首歌：你不用马上开心，这首歌陪你走一会儿。”

## 80–90 秒：留一个值得参与的方向

“原型已包含角色、广场、音乐互动与记忆。下一步是移动端体验、真正双端共听和授权音源。欢迎一起把音乐社交做得更温柔。”
