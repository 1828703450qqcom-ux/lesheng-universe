# Roadmap / 能力边界

## 当前原型可体验

- [x] 六步角色创建：照片、声音、故事、MBTI、代表歌曲与目标。
- [x] 浏览器本地人脸定位、色彩取样、音频基础特征与可解释的 SVG 角色。
- [x] 星空视觉、可旋转网格星球、音乐广场和角色互动卡片。
- [x] 社区心情、广场气泡、发现角色、送歌、音乐明信片、关系记忆。
- [x] 完整示例录音播放器、本地音频导入、跨页面播放。
- [x] 账号、JSON 持久化、通知、演示活动和市集收藏。
- [x] 角色引擎与音频状态机单元测试，干净数据的后端冒烟测试。

这些条目表示存在相应实现，不表示完成了所有设备、权限和并发场景的生产验收。

## 下一批值得贡献

- [ ] **移动端第一印象**：修复首次教程的视口定位、收敛播放器占屏、把首页角色和广场舞台提前。
- [ ] **更丰富的角色**：让更多外观令牌真实影响 SVG，增加角色风格与差异性测试。
- [ ] **可访问性**：字号、对比度、触控区域、焦点和屏幕阅读器检查。
- [ ] **真正双端共听**：远端状态订阅、房间权限、统一时钟、断线重连、跨设备自动化测试。
- [ ] **可靠持久化**：可替换数据访问层、事务、SQLite/PostgreSQL 适配及迁移。
- [ ] **隐私与安全**：更严格的输入、上传、WebSocket 消息校验、会话管理、限流和内容治理。
- [ ] **媒体兼容性**：真实 iPhone/Android/微信浏览器和弱网回归；快速跳曲压力测试仍有待定位的超时情况。

## 需要外部合作或新增能力

下列内容是产品愿景，不是现有仓库已经交付的功能：

- [ ] QQ 音乐官方账户、曲库及商业完整音源授权。
- [ ] AI 作曲、主题曲生成、声音克隆和完整语音语义理解。
- [ ] 艺人官方角色、真实票务权益、品牌合作与支付结算。
- [ ] 大规模社区运营、生产级推荐、全面内容审核。
